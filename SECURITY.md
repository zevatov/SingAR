# SECURITY.md — Модель угроз и безопасность SingAR

> Версия: 2.3.1 · Обновлён: 2026-09-28

## 1. Назначение и контекст безопасности

**SingAR** — нативный ассистент голосового ввода и vibe-кодинга для macOS. Приложение захватывает звук с микрофона при нажатии горячей клавиши, распознаёт речь (локально или через облачные API) и вставляет отполированный текст в активный редактор или поле ввода.

По умолчанию приложение работает в режиме **100% Offline**: модель **Whisper Large Turbo** выполняется локально на нейроядрах и GPU Apple Silicon (Metal). Аудиоданные не покидают устройство.

---

## 2. Границы доверия (Trust Boundaries)

| Граница | Что пересекает | Защита и гарантии |
|---|---|---|
| **Микрофон ⇄ Приложение** | Аудиопоток 16 кГц PCM | Захват идёт строго при зажатой горячей клавише (`Hold-to-Talk`) или активной сессии. Индикатор HUD наглядно информирует о записи. VAD отсекает шум. |
| **Приложение ⇄ Accessibility (AX)** | Вставка готового текста (`Cmd+V` / AX-замещение) | AX используется исключительно для определения целевого поля и вставки распознанного текста. Фоновый кейлоггинг или чтение экрана исключены. |
| **Приложение ⇄ macOS Keychain** | API-ключи облачных провайдеров (BYOK) | Ключи сохраняются с флагом `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`. Синхронизация через iCloud Keychain выключена. Ключи никогда не пишутся в `UserDefaults`. |
| **Приложение ⇄ Сеть (опционально)** | Аудиозапросы к Gemini / Groq / OpenRouter | Передача только по явному выбору пользователя. Ключи передаются строго в защищённых HTTP-заголовках (`x-goog-api-key`, `Authorization: Bearer`), никогда в URL query. |
| **Приложение ⇄ Диск** | Логи и история | В локальный лог `singar.log` пишется только длина и SHA-256 хэш текста (SHA-seam). Ротация логов при 1 МБ, хранение максимум 1 архива до 7 дней. |

## 3. Политика открытости и подпись кода

- Дистрибутив `SingAR.dmg` собирается открыто из исходного кода репозитория.
- Подпись выполняется в режиме ad-hoc (`codesign --sign -`) с включённым Hardened Runtime (`--options runtime`) и минимальным набором прав (entitlements: микрофон, распознавание речи, сетевой клиент).
- Для каждого релиза формируется файл контрольной суммы `SingAR.dmg.sha256`.
