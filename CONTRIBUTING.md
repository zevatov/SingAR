# Руководство по внесению изменений (Contributing)

Мы рады вкладу в развитие **SingAR**! Перед тем как отправить Pull Request или открыть Issue, ознакомьтесь с основными правилами проекта.

## 🎯 Принципы разработки

1. **Строгое следование канону Swift 6**:
   - Кодовая база компилируется в режиме Swift 6 с включённой строгой изоляцией потоков (`@MainActor`, `Sendable`).
   - Все изменения должны проходить сборку и тесты без предупреждений компилятора.

2. **Приватность и Zero Silent Fallback**:
   - Локальный режим Whisper Large Turbo никогда не должен отправлять аудиоданные в сеть.
   - Никаких скрытых откатов (Zero Silent Fallback) на Apple Speech при сбоях Whisper или отсутствии модели.
   - Любые изменения в ASR, пайплайнах диктовки и VAD должны сопровождаться unit-тестами в `Tests/SingARTests`.

3. **Конфиденциальность и безопасность**:
   - Запрещено коммитить API-ключи, токены или персональные данные. В CI работает автоматический `secret-scan`.
   - Версия приложения контролируется через единственный источник правды: `Sources/SingAR/Config/AppVersion.swift`. Хардкод версий в коде и скриптах запрещён правилом G4-4.

## 🛠️ Локальная разработка

### Требования
- macOS 14.0+ (Sonoma) или macOS 15.0+ (Sequoia)
- Apple Silicon Mac (M1/M2/M3/M4) с поддержкой Metal
- Xcode 15+ / Swift 6.0+
- Python 3 с `dmgbuild` (для генерации стилизованного DMG)

### Команды
```bash
# Сборка debug-бинарника
swift build

# Запуск полного набора тестов
swift test

# Проверка релизных скриптов (CI dry-run)
./scripts/build_dmg.sh --dry-run

# Сборка готового релизного дистрибутива
./scripts/build_dmg.sh
```

## 📋 Открытие Issues и Pull Requests

- **Баг-репорты**: указывайте версию macOS, используемую модель (Whisper / Gemini / Groq), модель Mac и шаги воспроизведения.
- **Pull Requests**: убедитесь, что `swift test` даёт 100% зелёный результат (0 failures), и `secret-scan` проходит успешно.
