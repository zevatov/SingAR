# SingAR 2.3.0 Release Notes

**Дата релиза:** 15 сентября 2026  
**Версия:** 2.3.0 (macOS 14.0+ Sonoma / macOS 15.0+ Sequoia)  
**Дистрибутив:** `SingAR.dmg`

---

## 🌟 Главные новшества

### 1. Полная изоляция Whisper и Zero Apple Speech Interference
- Apple Speech больше не запускается параллельно при выборе локального Whisper Large Turbo или облачных движков.
- Введён `NoopASREngine` в качестве безопасной заглушки.
- Устранены скрытые откаты (Zero Silent Fallback) на фоновый Apple Speech при сбоях Whisper или отсутствии скачанной модели. При отсутствии модели система вежливо сообщает об этом через HUD.

### 2. Режим чистого HUD для Whisper (`hudOnly`)
- Добавлен параметр `LiveDraftDisplayMode` (`.hudOnly` по умолчанию, либо `.inlineTyping`).
- В режиме `.hudOnly` промежуточный текст диктовки выводится только в парящий HUD-индикатор. Никаких лишних символов не печатается в активном редакторе (Cursor, VS Code, Xcode), а финальный чистовик мгновенно вставляется за 1 мс через системный буфер обмена без мерцания и паразитных бэкспейсов.

### 3. Звуковая обратная связь с кнопкой Mute в меню
- Добавлены нативные звуковые сигналы начала и окончания записи речи.
- В окно настроек добавлен тумблер включения/выключения звуковых эффектов.
- В заголовок меню добавлена быстрая кнопка Mute/Unmute в один клик.

### 4. Автоматическая проверка обновлений (`UpdateChecker`)
- Встроен легковесный сервис `@MainActor UpdateChecker`, опрашивающий GitHub Releases API (`zevatov/SingAR`) с откатом к официальному Telegram-каналу.
- В окне настроек выводится аккуратный бейдж при наличии новой версии.
- В настройки добавлена кнопка перехода в официальный Telegram-канал проекта.

### 5. Премиальное визуальное оформление и сборка DMG
- Сгенерирован новый высококачественный логотип (macOS Retina Squircle 1024x1024) с градиентом звуковой волны Electric Cyan ➔ Neon Violet и металлической фаской.
- Стилизован брендированный DMG-образ (`SingAR.dmg`) с кастомным темным фоном, drag-and-drop панелью, ссылками на репозиторий и Telegram, и иконкой тома.
- Имя DMG-пакета стандартизировано как `SingAR.dmg` (без версии в имени файла).

- **192 юнит-теста** проходят успешно (`192/192 passed`).
